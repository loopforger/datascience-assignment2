# 🎬 Movie Data Analysis

## Overview

This project analyzes a dataset of ~3000 movies to help a producer make data-driven decisions on movie production, actor selection, and collaborations.

---

## Objectives

* Identify the most profitable movie along with its producer, director, and actors
* Find the language with the highest average ROI
* List all unique movie genres
* Determine top 3 producers based on average ROI
* Analyze the most frequent actor (movies, genres, profits)
* Discover actor preferences of top 3 directors

---

## Dataset Features

* Title, Language, Genre
* Budget, Revenue, Profit
* ROI (Return on Investment)
* Actors, Director, Producer

---

## Tech Stack

* Python
* Pandas, NumPy
* Matplotlib / Seaborn

---

## Workflow

1. Data Cleaning & Validation
2. Feature Engineering (Profit, ROI)
3. Exploratory Data Analysis
4. Insight Generation

---

## Key Metrics

* **Profit** = Revenue − Budget
* **ROI** = (Profit / Budget) × 100
